# 신PC 백로그: 신PC도 놀지 않고 함께 진행할 과제

## 현재 상황
- 구솔라는 구PC 쪽 인바운드 3389 방화벽 확정과 텔레그램 수신 가능 여부 확인을 수행 중
- 관리자 권한 부족, 텔레그램 비GUI 확인 한계로 일부 미확정 상태
- 신PC는 구PC 쪽 제약을 기다리느라 별도 진행 없이 대기 중

## 문제 인식
- 구PC는 사양이 낮고 제약도 많음. 그런 쪽에만 일을 몰아붙이면 진척이 느림
- 신PC는 자원이 풍부하므로 신PC가 바로 할 수 있는 건 병행해서 진행해야 함
- 백로그를 구PC용/신PC용으로 나눠서 병행 가능한 구조를 만들어야 함

## 신PC 병행 가능 과제 후보

### 0순위 보조: 텔레그램 소통 실제 가능 여부 확인
- 신PC에서 텔레그램 발송/연결 가능 범위를 시험
- 민감정보 없이 가능한 범위에서만 확인
- 가능하면 구솔라와 실제로 알림이 오가는지 시험 설계
- 불가능하면 왜 불가능한지 정리

### 1순위: SSH 상호 활용 과제
- 신PC와 구PC 사이 SSH 사용 가능 여부 확인
- 신PC에서 SSH 서버/클라이언트 구성 가능 여부 정리
- 구PC에서 신PC 자원을 활용할 수 있는 경로 정리
- 신PC→구PC, 구PC→신PC 양방향 SSH 방향을 각각 확인
- 포트, 인증, 접근 제한, 보안 고려사항을 문서로 남김
- 신PC ssh 클라이언트 존재 여부 확인 완료: Git ssh.exe 존재
- 신PC sshd 서버 존재 여부: 미확인, 현재 ProgramData/ssh 및 sshd 서비스 미확인

## 신PC 우선 진행 항목(실제 확인 결과 반영)
- RDP 로그인 성공 여부 확인은 신PC에서 계속 진행
- 신PC SSH 클라이언트 사용 가능: ssh.exe 존재
- 신PC SSH 서버 준비 여부: 별도 시험 필요
- SSH 상호 활용 방향을 먼저 정리: 신PC→구PC, 구PC→신PC, 둘 다 필요한지
- 구PC SSH 존재 여부는 구솔라가 확인


### 2순위: 실제 RDP 로그인 성공 여부 확인
- 신PC에서 100.98.73.90 RDP 로그인 성공 여부 직접 확인
- mstsc만 여는 것으로 끝내지 않고 실제 로그인 정황 확인
- 성공/실패 여부를 신PC 측에서 관찰 가능한 범위에서 판정
- 실패 시 실패 정황 기록

### 3순위: 백로그 설계 정리
- 구PC용 TASK와 신PC용 TASK를 분리
- 병행 가능한 TASK를 병렬로 배치
- 한쪽이 막혀도 다른 쪽이 진행되게 설계
- "구PC 제약으로 대기"가 길어지지 않도록 신PC 선조치 항목 확보

## 신PC 즉시 실행 가능 항목
- 100.98.73.90 RDP 로그인 성공 여부 확인 시도 및 정황 기록
- SSH 가능 여부 사전 확인과 구성 방향 정리
- 텔레그램 발송 시험 가능 범위가 있는지 확인
- 백로그 구조를 문서로 정리

## 주의
- 구PC 제약을 신PC가 대신 해결하려고 무리하지 않는다
- 신PC가 할 수 있는 걸 먼저 하고, 구PC가 해야 하는 건 구솔라에게 맡긴다
- 결과로 남지 않으면 진행한 것으로 치지 않는다
