# TASK: 구솔라 0순위 후속 - 인바운드 3389 확정 + 텔레그램 수신 가능 여부 확인

## 목적
- 구PC 인바운드 3389 방화벽 Allow 규칙을 가능한 범위에서 확정한다
- 구솔라 쪽 텔레그램 수신 가능 여부를 확인한다

## 배경
- 구솔라가 현재 들어와 있음
- check-rdp-firewall-3389-100.98.73.90는 부분 완료됨
- 3389 LISTEN, TermService RUNNING, RDP 수신 설정은 확인됨
- 인바운드 3389 Allow 규칙은 관리자 권한 부족으로 미확정
- 텔레그램 수신 가능 여부는 아직 결과로 확인되지 않음

## 우선순위
지금 시점에서는 아래 두 항목이 0순위 후속이다.

1. 인바운드 3389 Allow 규칙 재확인
2. 구솔라 텔레그램 수신 가능 여부 확인

## ACTION 1: 인바운드 3389 허용 여부 재확인
- 가능하면 관리자 권한 PowerShell에서 실행한다
- Get-NetFirewallRule, Get-NetFirewallPortFilter 조합으로 TCP 3389 인바운드 Allow 규칙 존재 여부를 확인한다
- 기존에 확인된 정보(3389 LISTEN, TermService RUNNING, RDP-Tcp 포트/NLA/SecurityLayer, 방화벽 프로파일 활성화)도 함께 정리한다
- 관리자 권한 확보가 안 되면 그 사유를 남기고 미확정으로 끝낸다
- 긍정/부정/미확정 중 하나로 판정한다

## ACTION 2: 텔레그램 수신 가능 여부 확인
- 구솔라 쪽 텔레그램 수신 가능 여부를 확인한다
- 텔레그램 앱 사용 가능 여부
- 봇/채팅/채널 상태에서 알림을 받을 수 있는지
- 가능하다면 어떤 형태로 수신되는지
- 불가능하면 왜 불가능한지 기록한다
- 민감정보(토큰, 채팅 ID 등)는 남기지 않는다

## 결과 남기기
- 결과는 tasks/completed/ 또는 tasks/failed/에 남긴다
- 보고서는 reports/에 남긴다
- TASK_ID를 남긴다
- 작업 후 push한다

## 현재 상태 정리
- 구솔라: 현재 접속 가능
- 방화벽 3389: 부분 완료, 인바운드 Allow 미확정
- 텔레그램: 아직 구솔라 결과로 확인되지 않음
