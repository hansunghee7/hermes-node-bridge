# 구솔라 추가 지시: check-rdp-firewall-3389 확정 및 텔레그램 가능 여부 확인

## 목적
- 구PC 인바운드 3389 방화벽 허용 여부를 가능한 범위에서 확정한다
- 구솔라 쪽 텔레그램 수신 가능 여부를 확인한다

## 배경
- check-rdp-firewall-3389-100.98.73.90은 이미 부분 완료됨
- 3389 LISTEN, TermService RUNNING은 확인됨
- 인바운드 3389 방화벽 Allow 규칙은 관리자 권한 부족으로 미확인 상태
- 텔레그램 소통 가능 여부도 아직 구솔라 쪽 결과로 확정되지 않음

## 현재 최우선 과제
이 두 가지는 지금 구솔라가 들어와 있는 시점에서 바로 이어갈 수 있는 작업이다.

## ACTION 1
- 가능하면 관리자 권한 PowerShell에서 Get-NetFirewallRule로 인바운드 3389 관련 Allow 규칙 존재 여부를 다시 확인한다
- 기존에 확인한 정보(3389 LISTEN, TermService RUNNING, RDP-Tcp 포트, NLA=0, SecurityLayer=0, 방화벽 프로파일 활성화)도 함께 정리한다
- 권한 부족 등으로 확정이 안 되면 그 사유를 결과와 함께 남긴다
- 긍정/부정/미확정 중 하나로 끝낸다

## ACTION 2
- 구솔라 쪽 텔레그램 수신 가능 여부를 확인한다
- 텔레그램 앱이 있는지, 봇/채팅/채널 상태를 쓸 수 있는지
- 가능하다면 어떤 형태로 알림 수신이 되는지
- 불가능하면 왜 불가능한지 기록한다
- 다만 민감정보(토큰, 채팅 ID 등)는 남기지 않는다

## 결과 남기기
- 결과는 tasks/completed/ 또는 tasks/failed/에 남긴다
- 보고서는 reports/에 남긴다
- TASK_ID를 남긴다
- 작업 후 push한다

## 현재 필요한 것
- 구솔라가 지금 바로 처리 가능한 상태의 TASK
- 말로만 끝내지 않고 결과로 남기게 하는 것
- 구솔라가 결과를 push하면 신솔라가 직접 확인하게 하는 것
