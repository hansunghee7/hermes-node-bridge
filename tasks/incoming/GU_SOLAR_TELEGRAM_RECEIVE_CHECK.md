# 구솔라 텔레그램 수신 가능 여부 확인

## 목적
- 구PC에서 텔레그램 알림 수신이 실제 가능한지 가능한 범위에서 확인한다
- 신PC와의 텔레그램 소통이 실현될 수 있는지 확인한다

## 주의
- 민감정보는 묻지 않는다
- 봇 토큰, 채팅 ID, 비밀번호 같은 건 이 문서에 넣지 않는다
- 가능한 범위에서만 확인한다
- 앱 화면 상태로 확인 가능하면 그 상태로 남긴다

## 지금 배경
- 신PC는 텔레그램 발송 시험을 준비 중
- 구솔라는 텔레그램 앱이 실행 중임을 확인함
- 알림 수신 가능 여부는 아직 미확정
- 텔레그램은 핑만 오가는 신호 공간으로 쓰기로 정리됨

## 구솔라가 확인할 것
1. 구PC에서 텔레그램 앱이 실행되는지
2. 구PC에서 텔레그램 알림이 오는지
3. 구PC에서 텔레그램 알림을 받을 수 있는 환경인지
4. 구PC에서 텔레그램을 통해 신호를 받을 수 있는지
5. 텔레그램 수신이 불가능하면 그 이유를 남김

## 기록 방식
- 확인 가능한 범위에서만 남긴다
- 가능하면 실제 수신 시험 결과를 남긴다
- 불가능하면 불가능 사유를 남긴다
- 신PC 발송 시험과 연결되도록 상태를 맞춘다
