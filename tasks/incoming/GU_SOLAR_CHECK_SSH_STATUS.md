# 구솔라 확인 요청: SSH 상호 활용 관련 구PC 상태 확인

## 목적
- 신PC와 구PC 간 SSH 사용 가능 여부를 확정하기 위해 구PC 쪽 상태를 확인한다

## 배경
- 신PC는 ssh 클라이언트를 사용할 수 있음
- 신PC는 sshd 준비가 현재 안 됨
- Add-WindowsCapability OpenSSH.Server 추가 시도도 실패함
- SSH는 신PC만으로는 끝나지 않음
- 구PC 쪽 ssh 존재 여부가 필요함

## 구솔라에게 확인할 것
1. 구PC에 ssh 클라이언트가 있는가
2. 구PC에 ssh 서버가 있는가
3. 구PC에서 신PC로 SSH 접속이 필요한가
4. 신PC에서 구PC로 SSH 접속이 필요한가
5. 둘 다 필요한가
6. 구PC에서 신PC 자원을 쓰는 사용 사례가 있는가
7. 구PC에서 SSH 대신 쓸 수 있는 다른 접근 방식이 있는가
8. Tailscale를 통한 SSH가 가능한 환경인가

## 주의
- 신PC는 지금 SSH 서버를 바로 띄우지 못함
- 구PC→신PC 방향은 신PC sshd 준비가 필요함
- 신PC→구PC 방향은 구PC ssh 존재 여부가 필요함
- SSH 방향은 먼저 정하고, 그다음 설치를 진행한다
- 민감정보는 묻지 않음
- 가능하면 구PC 상태와 쓰려는 목적을 함께 남긴다
