# 업무 현황 업데이트 — 신PC 기준 (2026-09-15)

보고자: 신솔라 (신PC Hermes)
대상: 게르드
요약: 구PC(100.98.73.90)와의 연계 현황 및 미결 사항.

## 1. 완료된 작업

- RDP 복구 진단 (100.98.73.90): 구솔라 완료, 신PC 검증 진행 중
- check-rdp-firewall-3389-100.98.73.90: 구솔라 부분 완료
- 구솔라_0순위_후속_방화벽3389_확정_텔레그램확인: 구솔라 부분 완료 (결과/보고서 존재)
- SHINPC_TELEGRAM_SEND_TEST_RESULT: 신PC 시험 결과 정리됨 (실제 발송 미시험)
- SHINPC_SSH_TEST_RESULT: 신PC ssh 클라이언트 존재 확인, sshd 준비 불가 확인
- echo_test: 신PC에서 구솔라 역할 시뮬레이션 결과 존재 (실제 구PC 실행 미수행)
- 구PC 텔레그램 webhook 전환 (신PC): 완료. cloudflared quick tunnel URL 확보(`https://officer-renew-sheep-inside.trycloudflare.com`) 후 `.env`에 `TELEGRAM_WEBHOOK_URL`/`TELEGRAM_WEBHOOK_SECRET` 갱신 및 `hermes gateway restart` 수행. (2026-09-15)

## 2. 진행 중 / 미결

- 인바운드 3389 방화벽 허용 여부 확정: 미확정. 구PC 관리자 권한 부족으로 직접 조회 실패.
- 구솔라 텔레그램 수신 가능 여부: 미확정. 구PC에 텔레그램 앱 실행 중 확인, 실제 수신 시험 미진행.
- 신PC 텔레그램 발송 시험: 준비 완료, 실제 발송 미시험.
- SSH 상호 활용: 신PC→구PC 방향 우선 검토, 구PC ssh 존재 여부 미확인, 구PC→신PC 방향은 신PC sshd 필요(준비 불가 확인).
- Tailscale 단절 재발방지: 구솔라 선행 처리 대상.

## 3. 핵심 방해 요소

- 구PC 관리자 권한 부족 → 방화벽 규칙 직접 확인 실패
- 구PC Telegram 수신 시험 미실행 → 소통채널 확정 지연
- 신PC sshd 준비 불가 → SSH 양방향 활용 제한

## 4. 즉시 가능한 다음 조치

- 신PC 측에서 텔레그램 발송 시험 수행 (민감정보 제외)
- 구PC ssh 존재 여부 확인 (구솔라 요청 또는 구PC 직접 확인)
- Tailscale 상태 재점검 (현재 IP 100.98.73.90 유지 여부 등)
