## 상세

### 1. 방화벽 3389 Allow 규칙 확인 시도

- `Get-NetFirewallRule -DisplayName '*Remote Desktop*'` → Error 5 (PermissionDenied)
- `Get-NetFirewallRule -Direction Inbound -Action Allow` + 필터 → Error 5
- `Get-NetFirewallRule -All | Get-NetFirewallPortFilter | 로컬포트 3389 필터` → Error 5
- 관리자 권한 PowerShell 시작 시도 (`Start-Process -Verb RunAs`) → UAC 대화형 승인 필요, 비대화형 세션에서 자동 승인 불가

**결론**: 인바운드 3389 Allow 규칙 존재 여부는 미확정. 확정하려면 관리자 권한 PowerShell 필요.
