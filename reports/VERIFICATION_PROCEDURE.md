# 신PC 검증 절차

신솔라는 구솔라 결과를 받았을 때 아래 순서로 검증한다.

1. git pull로 최신 상태를 받는다.
2. TASK_ID가 무엇인지 확인한다.
3. tasks/completed/ 또는 tasks/failed/에 해당 TASK_ID 결과가 있는지 확인한다.
4. reports/에 보고가 있는지 확인한다.
5. 결과 파일에 TASK_ID, EXECUTOR, TARGET, STATUS가 있는지 확인한다.
6. ACTION_EXECUTED가 TASK의 ACTION과 대응되는지 확인한다.
7. RESULT가 SUCCESS_CRITERIA를 충족하는지 확인한다.
8. EVIDENCE가 실제 결과를 뒷받침하는지 확인한다.
9. 남은 조치나 사용자 조치 필요 여부를 확인한다.
10. 필요 시 재지시한다.

## 검증 판정

- 완료: 결과가 TASK 목표를 충족하고, 증거가 있고, 남은 조치가 관리 가능한 수준
- 부분완료: 일부 목표만 달성, 추가 작업 필요
- 실패: 목표 미달, 재시도 필요, 또는 사용자 조치 필요

## 검증 후 처리

- 완료면 해당 TASK 결과를 기록하고 다음 TASK로 넘어간다.
- 부분완료면 재지시 TASK를 만들 수 있다.
- 실패면 원인을 기록하고 재시도 또는 사용자 조치 요청 여부를 판단한다.

## 주의

- 구솔라 결과를 보고할 때 민감정보는 포함하지 않는다.
- IP나 토큰 같은 식별 정보는 필요한 최소 범위만 남긴다.
- 결과 평가는 문서 기준으로 한다.
